# Embedded assistant renderer

Linux Ask embeds the repository's local JavaScript, CSS and KaTeX WOFF2 fonts.
The original licenses and version list are retained here. DOMPurify is used
under the Apache-2.0 alternative; its MPL alternative is also retained.

KaTeX JavaScript/CSS is MIT. The fonts' embedded name records separately state
SIL Open Font License 1.1, copyright Design Science, Inc. (2009-2010) and
Khan Academy (2014-2018), with reserved KaTeX font names. Those exact statements
and all 20 font identities are in katex-font-copyrights.txt and
katex-font-metadata.json. The complete OFL text is in katex-font-OFL-1.1.txt,
obtained from SPDX's standard license text and checked against the official
text at https://openfontlicense.org/open-font-license-official-text/ .
Font files retain their original embedded copyright/license records.
